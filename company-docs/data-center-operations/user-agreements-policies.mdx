# User Agreements & Policies

FarmGPU operates with clear, transparent agreements designed for both individual builders and strategic partners.

## 1. Master Service Agreement (MSA)

The foundational agreement for all FarmGPU customers. It covers:

* Terms of usage and billing.
* Intellectual property (IP) protection and data privacy.
* Liability and indemnification.
* Governing law and dispute resolution.

## 2. GPU Owner Agreement

For revenue share partnerships and managed infrastructure services, FarmGPU provides specific agreements covering hardware ownership, operational responsibilities, and revenue sharing terms.

## 3. Inference API Policies

Data handling for the FarmGPU LLM inference API is governed by the
[Privacy Policy](/company-docs/legal/privacy-policy) and the
[Data Retention Policy](/company-docs/legal/data-retention-policy).
