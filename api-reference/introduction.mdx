The FarmGPU Cloud API is a REST API for everything the Cloud console does: launching GPU virtual machines and Intel TDX confidential instances, attaching block volumes and shared filesystems, and following usage. The console is built on this same API.

<Note>
  The Cloud API is in private preview. Tokens are issued by FarmGPU; contact your account team for access.
</Note>

## Base URL

```
https://api.farmgpu.com
```

Every resource path starts with `/v1`. Requests and responses are JSON.

## How changes work

Creating, starting, stopping or deleting a resource returns at once with the resource in a transitional state and an **operation**. The work then runs in the background. Poll the operation, or register a webhook, to learn when it has finished. See [Operations and webhooks](/api-reference/operations-and-webhooks).

An instance moves through these states:

```
provisioning → starting → running ⇄ stopping ⇄ stopped → terminated
```

`error` can follow any state. An instance in `error` can only be deleted.
